# 🎯 20天雅思冲6.5-7分计划系统

&gt; 专为雅思5分基础设计 | 听力口语重点突破 | 每日任务分明 | 纯前端免安装


📱 支持设备：电脑 / iPad / 手机（任意浏览器打开即可）

---

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 📅 **20天完整计划** | 每天4-5小时，听力/口语/阅读/写作四科均衡覆盖 |
| ✅ **任务打卡系统** | 点击完成任务，自动统计总进度 |
| 🔒 **答案解锁机制** | 练习题必须先做完，点击解锁才能查看答案与解析 |
| 📚 **资源库页面** | 汇总B站/新东方/雅思哥等免费网课链接 |
| 💾 **本地进度保存** | 使用浏览器 localStorage，刷新不丢失 |
| 🔄 **一键重置进度** | 支持重新开始学习 |

---

## 📖 20天计划概览

| 阶段 | 天数 | 重点 |
|------|------|------|
| **基础诊断期** | Day 1-3 | 水平自测 + 听力Section 1/2入门 + 口语Part 1基础 |
| **技巧强化期** | Day 4-10 | 听力地图题/配对题 + 阅读定位法 + 写作Task 1/2框架 + 口语Part 2/3 |
| **真题实战期** | Day 11-16 | 剑雅真题精练 + 全科模考 + 弱项专项突破 |
| **冲刺模考期** | Day 17-20 | 全真模考 + 错题复盘 + 考前状态调整 |

## 🚀 本地使用

1. 下载本仓库全部文件
2. 双击 `index.html` 用浏览器打开
3. 或在终端执行：
   ```bash
   cd ielts-20day-plan
   python3 -m http.server 8000
   # 然后访问 http://localhost:8000

   ⚠️ 注意事项
本系统使用浏览器 localStorage 保存学习进度，清除浏览器数据会导致进度丢失
建议每天学习完成后不要清除浏览器缓存
如需重新开始，点击页面上的 "🔄 重置进度" 按钮
